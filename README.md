# Tic Tac Toe

Ein einfaches Tic-Tac-Toe-Spiel für zwei Spieler im Browser – ohne Abhängigkeiten.

## Spielen

`index.html` im Browser öffnen. Spieler X beginnt, danach wird abwechselnd gesetzt.
Wer zuerst drei gleiche Zeichen in einer Reihe, Spalte oder Diagonale hat, gewinnt.
Der Punktestand bleibt erhalten, bis die Seite neu geladen wird.
